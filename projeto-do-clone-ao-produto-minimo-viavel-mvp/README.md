## 📝 Descrição do Projeto
O **Live Pro** é um editor de Markdown de alta performance projetado para oferecer uma experiência de escrita fluida, elegante e acessível. O objetivo principal é fornecer aos desenvolvedores e redatores uma ferramenta que transforma texto puro em visualizações ricas instantaneamente, eliminando a barreira entre o código e o resultado final.

Desenvolvido com foco em **UX/UI moderno**, o sistema utiliza processamento reativo para garantir que cada tecla digitada seja refletida no preview sem atrasos. Além disso, o projeto destaca-se pelo compromisso com a inclusão, integrando nativamente ferramentas de acessibilidade para a comunidade surda (LIBRAS) e garantindo uma experiência impecável em dispositivos móveis.

## 🚀 Tecnologias Utilizadas
* **Framework:** React 19 + Vite
* **Linguagem:** TypeScript
* **Estilização:** Tailwind CSS 4
* **Animações:** Framer Motion (Motion)
* **Processamento:** React-Markdown + RemarkGFM
* **Acessibilidade:** Integração VLibras

## 📊 Resultados e Aprendizados
O projeto alcançou um nível de polimento profissional, unindo performance técnica com design sofisticado.
* **Performance Reativa:** Implementei um pipeline de renderização que mantém o frame rate estável mesmo em documentos extensos.
* **Acessibilidade Inclusiva:** Integrei o widget VLibras, permitindo que todo o conteúdo seja traduzido para a Língua Brasileira de Sinais em tempo real.
* **Design Mobile-First:** O layout se adapta dinamicamente, alternando entre modos de edição e visualização de forma inteligente conforme o tamanho da tela.

## 🔧 Como Executar
1. Clone o repositório.
2. Instale as dependências: `npm install`.
3. Execute o servidor de desenvolvimento: `npm run dev`.
4. Acesse: `http://localhost:3000`.
